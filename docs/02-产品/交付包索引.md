## 一、品牌

**见微 Pinpoint** —— 见微知著：从一个微小信号（`PHPSESSID` cookie）看出整体风险；
Pinpoint：从 254 台候选精确定位到 1 台需要处置的机器。

图形为**四角取景框 + 中心实心点**：取景框是资产范围，中心点是那一个真正需要处置的目标。
纯几何、单色扁平，16px 到 512px 都成立。已同步到网页标签与 favicon（内联 SVG，零外部依赖）。

**快速开始**

```powershell
cd php2shell-sentinel
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[all]"
.\scripts\start-console.ps1          # http://127.0.0.1:18080/
```

**命令速查**

```powershell
p2s discover --cidr 192.168.1.0/24 --report reports/   # 设备发现
p2s assets   --host 192.168.1.1 --report reports/       # 资产测绘
p2s probe    --url https://x/      --report reports/     # URL 探测
p2s logs     --file access.log     --report reports/     # 日志分析
p2s host     --report reports/                            # 主机侧检测
p2s ioc      --scan-file sample.txt                       # IOC 匹配
p2s rules    --format json                              # 规则导出
p2s serve    --port 18080                               # Web 控制台
```

## 重要提醒

1. **控制台已加登录口令**（`P2S_CONSOLE_PASSWORD`），默认只监听 `127.0.0.1`；
   对外暴露前请同时配置反向代理与 HTTPS。
2. **日志分析有路径白名单**：只能读上传目录、`./logs`、`../samples`，
   以及 `P2S_LOG_ROOTS` 追加的目录，避免被当成任意文件读取接口。
3. **扫描前必须取得书面授权**：资产范围、时段、IDS/WAF 加白名单策略。
4. **本工具只做资产识别与暴露面评估，不发利用载荷、不修改被检系统**。
5. **修复唯一完整方案是升级 PHP 到 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 并重启全部 worker**。
